# M&M Abogados – Web corporativa
Vite + React 18 + Tailwind 3 + Framer Motion + Lucide + React Router 6 + react-helmet-async.

    npm install && npm run dev

- Datos centralizados: `src/config/site.js` (contacto, sedes, servicios, equipo, posts).
- Admin: `/admin/blog` (clave demo en `SITE.adminPassword`; reemplazar por auth real y API).
- Imágenes: logo en `public/logo.png`; fotos de abogados/blog son placeholders (`animate-pulse`).
